Learning project notice: This is a personal portfolio built for learning purposes. Visitor analytics are collected solely to understand traffic patterns on a self-hosted server. No data is sold, shared with third parties, or used for advertising.

What are cookies?

Cookies are small text files stored in your browser. This site uses localStorage (a browser storage mechanism similar to cookies) to remember your consent choice so the banner does not re-appear on every visit.

What we collect

Storage duration

  • Consent record — stored in localStorage for 90 days, then you will be asked again.
  • Session flag — stored in sessionStorage, deleted automatically when you close the tab.
  • Analytics data — stored on a self-hosted server with no defined retention limit at this time.

Your choices

  • Accept all — analytics event is sent once per session.
  • Only essentials / Refuse — no analytics data is sent. The consent record is still saved locally so the banner does not re-appear every visit.

How to withdraw consent

At any time, click "Cookie preferences" in the footer of any page. This clears your stored choice and reloads the page, showing the banner again so you can make a new selection.

You can also clear site data manually via your browser: DevTools → Application → Local Storage → delete cookie_consent.

Third parties
